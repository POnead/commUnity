## Findings

### QA-A01 — Nav badge count concatenated to label without separator (Low, Accessibility)
**One Lighthouse failure on the dashboard.**

- Observed: Lighthouse `label-content-name-mismatch`. Nav links render the badge count glued to the label text, e.g. visible text "Approval queue1" with `aria-label="Approval queue, 1 pending requests"`. The visible text is not a substring of the accessible name, so screen readers announce a different label than what is shown.
- Affected elements: the "Approval queue" and "Notifications" nav links (badges "1" and "2").
- Impact: confusing for screen-reader users; no task loss. Workaround: none.
- Proposed fix (not applied): insert a space/separator between the label and the badge, or set the aria-label to contain the exact visible text (e.g. "Approval queue 1").
