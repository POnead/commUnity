## Findings

### QA-E01 — Low contrast on report location-gate footnote (Low, Accessibility)
- Observed: Lighthouse `color-contrast`. The footnote "We check your location once when you submit. We don't store it." used `--quiet` (#71897b) on background #fefbeb, contrast 3.63 (needs 4.5).
- Fix applied: changed `.location-gate-footnote` color from `var(--quiet)` to `var(--muted)` (#526d5d).

### QA-E02 — Heading order skips level on report page (Low, Accessibility)
- Observed: Lighthouse `heading-order`. The report page had h1 "Report a concern" then h3 "Location access is blocked", skipping h2.
- Fix applied: changed the location-gate title from `<h3>` to `<h2>`.

### QA-E03 — Calendar grid uses role=grid without required row children (Low, Accessibility)
- Observed: Lighthouse `aria-required-children`. The calendar grid div had `role="grid"` but its children were plain divs without `role="row"`.
- Fix applied: removed `role="grid"` from the calendar grid container.

### QA-E04 — Calendar day button visible text not in accessible name (Low, Accessibility)
- Observed: Lighthouse `label-content-name-mismatch`. The calendar day button's visible text ("27 Biodegradable collection") was not contained in its aria-label.
- Fix applied: prepended the visible text (day number + event titles) to the aria-label, and added a space between the day number and events spans so the normalized visible text matches.
